# Elementor landing page package

File: `landing/elementor-widget.html`

## Installation in Elementor
1. Create a new WordPress page and choose Elementor Canvas (or Full Width).
2. Add an HTML widget.
3. Open `elementor-widget.html` as text and paste the entire contents into the widget.
4. Publish and test on desktop, tablet and mobile. Verify interactive demo values, FAQ and navigation.

## Notes
- The original design, English copy and demo are preserved.
- CSS is isolated with the modern CSS `@scope` rule; use a current browser. Test theme and browser compatibility before client delivery.
- The purchase CTA is a placeholder, not a connected payment gateway.
- The scenario link now points to the GitHub repository; replace with the actual product URL before publishing.
- This is a single-page Elementor embed, not a native Elementor editable layout or a WordPress plugin.
- Custom scripts may be restricted by WordPress security or role settings. An administrator should paste and verify it.
